Design notes what changed and why

This is a redesign of the product’s structure, not a reskin. The test applied to every element: does it carry information a professional would miss if it were gone? If not, it went. What follows is the short version of the argument.

Navigation is a sentence, not a sidebar

The fastest financial software ever built runs on a command line, and there is a reason no trader asks for it to be replaced with icons. UAA follows: one line at the top takes a ticker, several tickers, a filter expression, or a question. The function row beneath it is the entire site map — seven words. There is no sidebar. Nothing is more than one keystroke of intent away, and the interface never has to guess which of six panels you meant.

The decision line comes first on every page

Every page opens with the same rule under the masthead: what here needs deciding, if anything. Most days, most pages honestly answer “nothing” — and printing that is as valuable as printing an alert, because it lets you close the laptop. This is the product’s one non-negotiable ritual, and the thing a user should miss most in any other software.

Rules instead of boxes

There are no cards. Content is separated the way a broadsheet separates it: a hairline where two columns of different kinds meet, whitespace where the same kind continues, and nothing at all where the type already makes the boundary obvious. Removing the boxes bought back roughly a fifth of every screen, and the density went up while the clutter went down. Borders were doing the job hierarchy should have been doing.

One accent, one meaning

Amber marks exactly one thing: a decision that is open. It never decorates, never brands, never says “new.” Green and red belong to the market and are never borrowed for interface moods. Everything else is set in three grays. When a screen has no amber on it, that is the interface saying you can leave.

Numbers behave like numbers

Every figure is tabular, right-aligned, and set in the mono — including inside sentences. Scores never appear without their question (“Fit — in your book, today”), because a bare 58 is a Rorschach test. Where an engine has nothing to say, it prints no basis rather than a fabricated midpoint. The absence of a number is data.

The writing is part of the interface

Table cells get findings, not descriptions — “Value 38 is the whole debate in one cell” tells you where to look next; “Palantir Technologies Inc.” tells you nothing you didn’t know. Empty states say what would fill them. Alerts quote the user’s own note back with its date, because the strongest argument with any investor is the one they wrote themselves. No sentence congratulates, apologizes, or sells.

What was deliberately not designed

Onboarding tours, achievement states, AI sparkle icons, skeleton shimmer, hover lifts, and the settings page as a personality statement. A professional tool earns affection by being fast and right, and by leaving the user alone at every moment when it has nothing to add.
